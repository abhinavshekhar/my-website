# F Block event templates

Reusable posters and copy for **VIT Chennai F Block Hostel** events.

## Use in Cursor

Project skill: `.cursor/skills/vit-fblock-event/`

Ask the agent things like:

- “Make an F Block Diwali poster for 20 Oct, 6 PM”
- “Freshers night template, ground floor, free entry”
- `/vit-fblock-event` then describe the event

The skill fills the Onaverse-style layout (header, brush title, logistics,
activities, surprise strip, footer, credits) and swaps palettes by event type.

## Use in the browser

Open `fblock-events/poster.html`:

1. Choose an event type (Onam, Diwali, Holi, Pongal, Eid, Christmas, Freshers,
   Farewell, Hostel Day, Sports, Tech, Quiz, Music, or generic).
2. Edit title, time, activities.
3. **Print / PDF** (A4 portrait, enable background graphics).
4. **Copy WhatsApp** for the hostel group caption.
