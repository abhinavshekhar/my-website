# F Block poster brand

Shared layout tokens. Swap only the type palette and motifs.

## Shared tokens

- Page: A4 portrait (`210mm × 297mm`), cream paper texture
- Corners: 0 (print full-bleed) or 18px on screen
- Header lockup: serif / high-contrast small caps
- Title: heavy brush / display script
- Body / logistics: clean sans
- Icon style: single-weight outline, 2px stroke, no filled skeuomorphism
