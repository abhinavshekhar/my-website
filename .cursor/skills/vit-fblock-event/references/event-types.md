# F Block event types

Pick one `type` key. Suggested activities are defaults — replace with the
user's list.

| `diwali` | Deepverse / Lights of F | Light Up the Block | Diyas, Rangoli, Sparklers (safe zone), Sweets, Music, Games |
| `holi` | Holi High / Rangverse | Color the Corridor | Color play, Dhol, Thandai, Games, Music, Photo booth |
| `pongal` | Pongal Pass / Harvest @ F | Sweet Start, Strong Block | Pongal pot, Kolam, Folk games, Music, Feast |

## Timing defaults (hostel-friendly)

- Morning cultural (Onam-style): **7:00 AM – 3:00 PM**
- Evening festival: **5:30 PM – 9:30 PM**
- Night social: **8:00 PM – 11:00 PM** (stay inside hostel rules)
- Sports: **6:30 AM – 12:00 PM** or **4:00 PM – 7:00 PM**

Never invent fireworks, alcohol, or off-campus after-hours that would break
hostel policy. If the user asks for those, keep copy campus-safe and note the
constraint.
